About RiverWatch

RiverWatch is a lightweight Manifest V3 Chrome extension designed for kayakers, anglers, river enthusiasts, and flood-prone communities. It pulls data directly from official NOAA water prediction endpoints to deliver instant stage height readings without requiring complex web navigation.

Key Features

  • Live Toolbar Badge: Real-time river stage height color-coded by official NOAA flood severity categories.
  • Interactive Hydrograph: Smooth 3-day historical trend graph with precise hover tooltips.
  • Flow & Threshold Metrics: Discharge rates (kcfs) and official flood stages (Action, Minor, Moderate, Major).
  • Custom Station Selection: Monitor any 5-character NWSLI gauge in the United States.

Privacy Policy

Effective Date: August 2026

1. Overview

RiverWatch is committed to protecting user privacy. RiverWatch does not collect, store, track, transmit, or share any personal information, sensitive user data, browsing history, or analytics.

2. Data Usage & Local Storage

  • Local Preferences: RiverWatch saves your selected station code (e.g., WLGW2) and appearance theme locally using Chrome's standard chrome.storage API. This data remains strictly on your device and is never sent to external servers or third parties.
  • Public NOAA API Requests: The extension makes network requests directly to public National Oceanic and Atmospheric Administration (NOAA) endpoints (https://api.water.noaa.gov/*) solely to fetch real-time river stage levels, streamflow metrics, and flood threshold metadata. No personal identifiers or tracking telemetry are included with these API requests.

3. Third-Party Code & Analytics

RiverWatch contains no advertising, tracking scripts, telemetry, remote code, or third-party analytics.
